## ⭐ Featured — Ad Order Automation & Distribution Platform

*Designed and built under contract for a US broadcast ad-distribution company.*

> TV and radio commercials used to be processed by hand — every ad checked, converted to each station's format, packaged into station documents, and delivered one destination at a time. I designed and built the platform that automates the whole pipeline end to end, from upload to confirmed delivery at every station, and I own the backend architecture, the workflow engine, and the DevOps.

**What I built**

- **Durable, long-running order workflows (Temporal)** — every step is persisted, auto-retried, and resumes after a crash, so no order is ever lost
- **An orchestrated per-order pipeline** — media validation → preview/proxy generation → original backup → per-station format lookup → transcode once per format → document generation (PDF, XML, BXF) → per-station delivery → client notification → completion
- **Parallel per-station child workflows**, each delivering by its own method (Signiant, Aspera, FTP, S3, Google Drive)
- **Format-aware transcoding** — stations grouped by format so each conversion runs once, load-balanced across multiple Vantage servers with FFmpeg as fallback
- **Human-in-the-loop** — on a bad file the workflow emails the client, pauses, then resumes automatically on re-upload or cancel
- **Dropped into existing C# services over RabbitMQ** — automation added without a rewrite
- **Independently scaling workers** plus a live operations dashboard with full per-order history

`End-to-end automation of a manual pipeline` · `Parallel multi-station delivery, each in its own format` · `Fault-tolerant durable execution` · `US enterprise client, direct contract`

**Stack:** Temporal · Go · Python · RabbitMQ · C# integration · PostgreSQL · Kubernetes · Docker · CI/CD · FFmpeg · Vantage · Signiant · Aspera · S3
