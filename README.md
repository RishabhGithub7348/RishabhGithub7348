## ⭐ Featured — SpotBeam

**Ad Order Automation & Distribution Platform** · *On The Spot Media (OTSM), USA*

> OTSM is a US broadcast ad-distribution company (founded 2005; New York & Los Angeles) that delivers TV and radio commercials to stations nationwide. Every ad order used to be handled by hand — checking files, generating previews, converting to each station's format, building station documents, and delivering to every destination. **We designed and built the system that automates the whole pipeline end to end**, from upload to confirmed delivery at every station, and we own the backend architecture, the workflow engine, and the DevOps under direct contract.

**What we built**

- **Durable, long-running order workflows on Temporal** — every step is persisted, auto-retried, and resumes after a crash, so no order is ever lost
- **An orchestrated per-order pipeline** — media validation → preview/proxy generation → original backup → per-station format lookup → transcode once per format → document generation (PDF, XML, BXF) → per-station delivery → client notification → completion
- **Parallel per-station child workflows**, each delivering by its own method (Signiant, Aspera, FTP, S3, Google Drive)
- **Smart transcoding** — stations grouped by format so each conversion runs once, load-balanced across multiple Vantage servers with FFmpeg as backup
- **Human-in-the-loop** — on a bad file the workflow emails the client, pauses, then resumes automatically on re-upload or cancel
- **Dropped into OTSM's existing C# services over RabbitMQ** — automation added without a rewrite
- **Independently scaling task queues & workers** (media, transcode, docs, notify, distribution, orchestrator) plus a live operations dashboard with full per-order history

`End-to-end automation of a manual pipeline` · `Parallel multi-station delivery, each in its own format` · `Fault-tolerant durable execution` · `US enterprise client, direct contract`

**Stack:** Temporal · Go · Python · RabbitMQ · C# integration · PostgreSQL · Kubernetes · Docker · CI/CD · FFmpeg · Vantage · Signiant · Aspera · S3
